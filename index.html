Features

Tutto ciò che ti serve

Un sistema completo pensato per gestire la moderazione del tuo server FiveM in modo preciso, rapido e documentato.

Gestione giocatori

Registro completo di tutti i giocatori con licenza FiveM, Discord ID, storico sanzioni e stato aggiornato in tempo reale.

Ban & Warn system

Emetti warn, ban temporanei, ban permanenti e "Last Chance" direttamente dalla dashboard, con motivo, moderatore e timestamp tracciati.

Statistiche disciplinari

Dashboard con grafici e metriche su warn attivi, ban temporanei, permaban e Last Chance per tenere tutto sotto controllo.

Integrazione Discord

Sincronizzazione con il tuo server Discord: avatar, banner e lista membri importati automaticamente tramite Bot Token.

Verifica licenze live

API REST integrata per verificare la licenza FiveM di un giocatore al momento del join, bloccando automaticamente i bannati.

Activity feed in tempo reale

Stream live di tutte le azioni di moderazione: chi ha fatto cosa, quando e su quale giocatore. Audit completo e sempre accessibile.

About

Cos'è Watchdog

Watchdog è un sistema di moderazione self-hosted per server FiveM, costruito con Node.js, Express e SQLite. Nasce dall'esigenza di avere uno strumento semplice, veloce e completo per gestire le sanzioni disciplinari.

Il progetto espone una REST API che si integra direttamente con gli script Lua del server FiveM per verificare ban e licenze al momento del join, mentre la dashboard web permette di gestire giocatori, staff e statistiche in tempo reale.

Self-hosted – gira sul tuo server, i dati non escono mai dalla tua macchina.
Integrazione FiveM nativa – endpoint `/api/check-license` per bloccare i bannati al join.
Discord sync – avatar, banner e lista membri sincronizzati via Bot Token.
