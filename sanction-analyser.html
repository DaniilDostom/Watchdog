Architettura & Funzionamento

Come funziona SanctionAnalyser

Una panoramica completa su come il sistema gestisce l'accesso del server owner, l'abilitazione automatica degli staffer, la verifica istantanea delle licenze FiveM in gioco e la protezione blindata da leak e vulnerabilità.

Modello SaaS Cloud

Zero installazioni, massima semplicità

Tutto il sistema è ospitato su infrastruttura cloud sicura. Tu e il tuo team accedete direttamente via browser con Discord, senza dover configurare server web o database complessi.

1

L'Owner compra la licenza

Nessun file sorgente da scaricare. La licenza attiva il server nel sistema centrale Watchdog.

  • L'Owner esegue il Login con Discord nel portale.
  • Il sistema lo riconosce istantaneamente come Owner del Server.
  • Sblocca il pannello di amministrazione completo e la generazione della Secret API Key.
2

Gestione Staffer immediata

L'Owner non deve creare account o password manuali per i suoi moderatori.

  • L'Owner inserisce il Discord ID dello staffer nella sezione Staffers.
  • Lo staffer apre il sito e clicca "Accedi con Discord".
  • Watchdog verifica l'ID in tempo reale e garantisce l'accesso operativo al solo server assegnato.
  • Se lo staffer viene rimosso dalla lista, l'accesso viene revocato all'istante.
3

Moderazione & Forensics

Tutto lo staff opera da una dashboard grafica moderna, ricca di statistiche e storico.

  • Assegnazione rapida di Warn, Temp-Ban e Perm-Ban.
  • Calcolo automatico delle scadenze e rimozione temporale.
  • Storico cronologico di tutte le azioni e modifiche (Audit Log).
Integrazione In-Game

Come funziona il controllo del Server FiveM

Il server FiveM interagisce con Watchdog tramite una risorsa Lua leggera inserita nella cartella resources/. Ogni giocatore che tenta di entrare viene verificato prima ancora di spawnare.

1. Il Giocatore prova a connettersi

Durante l'evento playerConnecting, lo script FiveM intercetta la licenza (es. license:2d8f...) e il Discord ID.

2. Chiamata API con Secret Key

Lo script contatta il backend Watchdog inviando la Secret API Key per verificare lo stato del giocatore.

3. Decisione istantanea senza riavvii

Se il giocatore è bannato (permanente o temporaneo ancora attivo), l'accesso viene bloccato a schermo con motivo e scadenza esatta. Altrimenti entra normalmente.

Configurazione Risorsa FiveM config.lua
-- Configurazione Watchdog Sync
Config = {}

Config.ApiUrl = "https://api.watchdogsystem.com"
Config.ServerKey = "wd_live_9f83ac124b89e21..."
Config.KickMessage = "Sei stato sanzionato da Watchdog."
Sincronizzazione in tempo reale

Se uno staffer banna o sbanna un giocatore dalla dashboard web, l'effetto è immediato: non serve riavviare o ricaricare il server FiveM!

Protezione Totale

Blindato contro Breach, Leak e Manomissioni

La sicurezza dei dati della tua community e l'integrità del sistema sono al primo posto. Ecco le misure ingegnerizzate in Watchdog:

Zero Leak del Codice

Essendo un'applicazione SaaS, il codice sorgente backend e la logica risiedono unicamente sui nostri server protetti. Nessun cliente o terzo ha accesso ai file sorgente o ai database interni.

Isolamento Multi-Tenant

I dati di ogni server sono rigorosamente separati: nessun amministratore o moderatore può visualizzare, cercare o interferire con i registri di altri server.

Autenticazione Crittografata

Accesso sicuro tramite protocollo OAuth2 di Discord con sessioni crittografate, chiavi API uniche per ogni server FiveM e token con rotazione sicura.

Anti-DDoS & Rate Limiting

Protezione integrata contro attacchi di forza bruta e spam di richieste, con limiti intelligenti per IP e filtri WAF Cloudflare enterprise.

Audit Log Inviolabile

Ogni sanzione, modifica, rimozione o accesso viene registrato con timestamp e identificativo del moderatore, impedendo abusi di potere interni allo staff.

Backup Automatici Continui

Salvataggi periodici ridondati del database con snapshot giornalieri, proteggendo il tuo server da perdite accidentali di dati o corruzioni.
